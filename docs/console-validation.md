# Console 业务迁移验证记录

日期：2026-09-24。范围：任务与报告控制台首批业务接入，沿用 x.ai 样式规范。本批不引入 Spec Runtime，不改写上层验收标准，也不改变 Browser Node 的执行协议。

## 已实现

- 管理凭据连接、任务列表、字面搜索、状态筛选、游标分页和可见页面刷新。
- 提交上层已定义的任务 JSON、服务器结构与领域校验、任务详情、取消确认。
- 原始验收项、逐项结论、执行异常、任务生命周期与独立的资源关闭状态。
- 有报告任务索引、全部证据和逐项证据入口、DOM/PNG 预览、摘要核对、报告 JSON 预览与复制、下载入口。
- 节点连接、能力、节点池、容量及实际占用查询。占用取节点上报与控制面预留的并集。
- 三份读取 Schema 和同源生成类型、列表索引迁移、开发同源代理。

API 本批新增验证：同毫秒不同微秒和相同创建时间下分页不漏记录；筛选条件绑定游标；搜索中的 `%` 按字面匹配；非法参数与 Worker 凭据被拒绝；真实响应符合读取 Schema；任务缺少报告时保持 null；节点占用不重复计数且不提前释放。原调度、去重、证据与报告闭环测试继续运行。

Console 客户端测试覆盖：写操作网络故障不自动重试、同源路径限制、空格搜索编码、证据类型与摘要不符时拒绝展示、超大内容停止读取。客户端测试使用受控 fetch，不证明真实网络可用性。

## 浏览器联调

使用独立临时 PostgreSQL 数据库和 `tests/console/serve-fixture.mjs`，走真实 API、WebSocket、数据库和证据存储。准备 28 条排队任务以及 EXECUTED、BLOCKED、ERROR 三份报告。浏览器节点由 SimulatedNode 模拟，PNG 是最小测试图片；这些记录明确标注为联调夹具。

已观察到：

1. 错误凭据返回明确错误；正确凭据进入列表。开发代理缺失时显示 JSON 响应错误，重启配置后的 Vite 恢复连接。
2. 第一页 25 条，下一页显示其余任务；中文含空格搜索准确返回一条匹配记录。
3. 报告列表将验收通过、执行受阻和执行错误分别显示，受阻和错误没有产品 PASSED/FAILED 结论。
4. DOM 证据显示原观察 JSON，PNG 成功加载，两者显示 SHA-256 已核对。
5. 非法任务定义被拒绝；有效任务通过页面提交到数据库；确认取消后详情显示 CANCELLED，排队任务没有伪造浏览器会话。
6. 节点页面显示真实协议夹具的在线状态、0/2 占用与能力。
7. 报告导出 JSON 包含原任务 ID、1 个验收项、2 份证据；复制后显示成功。
8. 桌面 1280px 和窄屏 390px、320px 检查；主题切换正常，页面本身无横向溢出，宽表格在自身容器内横向滚动。
9. 页面重载后要求重新输入凭据。联调没有观察到未处理的 JavaScript 异常。
10. 关闭控制面后，页面保留上次成功报告并显示读取错误和时间；断开连接后清除数据并返回空凭据输入。临时 API、数据库和证据目录均已清理。

下载入口使用浏览器 Blob 链接。内嵌浏览器没有提供可核实的文件下载回执，本批确认了 JSON 预览、复制和证据内容，不将“文件已保存到磁盘”列为通过项。

## 运行边界与后续批次

当前是管理员操作台，没有 SSO、多租户或公网会话体系。生产使用同源 HTTPS 部署，Vite 代理只用于开发。管理员凭据验证成功后保存在当前站点的浏览器 localStorage，再次进入时自动填入，仍需点击连接；连接页提供清除入口。人工处理链接令牌不纳入此记忆功能。

本轮已补节点配对码签发、撤销和轮换界面，以及人工介入、登录状态保存、最近操作和 NETWORK 证据入口。浏览器联调验证了请求介入、安全点交接、观察、人工按键消耗一次动作、成功记录及交还 AUTO；登录状态的实际恢复由真实 Chrome 测试覆盖。真实内网 VM、真实模型业务质量、业务登录有效性与主机重启仍待环境验收。以上 UI/协议夹具不能替代这些验收。
