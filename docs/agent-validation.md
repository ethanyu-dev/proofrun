# 执行 Agent 验证记录

日期：2026-09-24。模型服务地址、模型名、密钥、视觉能力和输出预算参数都由环境配置，不预设供应商。所有本批模型回复来自本地 HTTP 协议夹具，没有调用真实收费模型。

## 实现范围

`apps/agent` 已实现串行 worker、领取协议、独立续租、远端导航预检、观察与动作循环、逐项验收和证据报告。上下文和调用轮数有上限；点击与填写注入当前观察身份；模型输出不能管理会话或签发租约。

API 支持 EXECUTED/BLOCKED/ERROR 报告，统一校验标准覆盖、证据归属和产品 verdict。终态后的 ERROR 报告仅补充元数据，取消、超时和失败不能被迟到报告复活。报告附加命令 ID、动作数、模型调用数、耗时和已解析回复中的 token 用量。

Node 的观察改为完整快照，包含成功提示等非交互内容；保留原有注册、资源池、远端连接、队列、会话监管和开放 Shadow DOM 处理。

## Linux 真实浏览器场景

`tests/agent/linux_real_browser.py` 使用真实 worker CLI、API、PostgreSQL、Rust Node、systemd、固定 0.38.1 原生 agent-browser 和 Chromium。页面服务独立记录普通表单和两层开放 Shadow DOM 表单的实际写入；模型回复仍由脚本生成。

```sh
# 提供与 Docker 容器架构一致、具有执行权限的 Linux 原生二进制。
export PROOFRUN_TEST_AGENT_BROWSER=/absolute/path/agent-browser-linux-arm64
pnpm test:agent:linux
```

脚本创建独占的 PostgreSQL 和 systemd 容器、网络以及临时数据，结束时回收。测试镜像安装 Chromium；privileged 仅用于该一次性容器内的 systemd/cgroup，不是生产部署配置。

本次完整场景通过：普通表单提交 Ada、两层开放 Shadow DOM 表单提交 Lin，页面服务独立确认恰好两次写入。最终观察包含两条非交互成功文本；14 份证据（7 DOM、7 PNG）均逐份下载核实 SHA-256；API 记录关闭确认，systemd 检查没有残留活动会话服务。

共 7 次脚本模型调用、5 个 browser.act（包含初始导航）、14 条浏览器命令。先前上传只靠 10 秒周期，且可用事件等待心跳，场景从领取到报告生成耗时 74.773 秒。改为结果 ACK 唤醒上传、持久化后即时发送 artifact.available，仍保留 10 秒重试与 outbox 心跳补发；同一场景再次运行耗时 4.224 秒。

以上各为一次本地容器测量，不含安装和构建，也不含最终报告提交与关闭的额外耗时。脚本模型几乎没有推理延迟，不能外推真实模型或生产 VM 的整体提速。fixture 回传的 token 数是模拟数据，不用于计费或成本结论。

## 剩余迁移补充验证

本轮执行器单元场景增至 19 个，新增人工交接后丢弃旧模型回复、禁止未授权介入、等待不延长原截止时间、初始观察遇到控制权切换不重放导航、报告提交暂停后取消仍交付故障报告。API 集成增至 7 个场景，其中真实 worker 经 HTTP 请求人工、管理员执行一次按键、恢复观察后完成报告，并共享原动作预算。

Linux Chromium 完整链路再次通过：7 次脚本模型调用、5 次动作、14 份摘要匹配证据、两次独立业务写入和已确认会话关闭。本次执行循环 4.560 秒，仅为一次夹具测量，不构成性能基准。登录快照及网络元数据测试同时通过。真实模型与真实 VM 的边界不变。
