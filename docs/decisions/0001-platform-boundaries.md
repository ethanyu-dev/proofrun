# ADR 0001：独立仓库与职责边界

状态：采用。

ProofRun 使用独立 monorepo，不复制旧平台的 Spec 分析阶段、兼容协议或历史数据库迁移。Rust 与 TypeScript 工程共享协议源文件，可以统一变更、分别部署。

上层 Agent 负责需求和验收定义；平台内保留验证执行 Agent。远端浏览器节点的注册、排队、容量、内网访问能力必须保留。

旧项目作为设计和回归场景参考，重点继承租约隔离、进程关闭、未知写入处理和证据判定规则。新旧平台不要求数据或协议互通，必要的运营数据迁移另行设计。

拆分多个仓库不作为当前目标，以免新协议需要跨仓库协调。部署边界不等于仓库边界。
