# DOM 观察与上下文边界

节点采集当前 frame 的正文、可操作目标、文档语言、视口与证据引用。真实操作由 observationId 和当前 target 绑定；跨轮比较键仅用于观察差分，不授予操作权限。

当前实现支持原生/ARIA 控件、真实点击监听节点、open Shadow DOM、iframe 和溢出容器。禁用、只读和密码控件分别限制能力和脱敏；隐藏内容和未渲染的虚拟列表项不能作为完整业务证据。portal 关系无法确认时保留未知，不根据几何位置猜测业务归属。

正文、控件与原生选项各自有界。原生 select 超过 200 项会报告省略；没有 browser.query/browser.read、快照分页或选项续读工具。coverage、omitted、truncated 只描述观察缺口，不能据缺失内容断言业务对象不存在。

Agent 用 [唯一 context](agent-loop-simplification-design.md) 投影当前 page，保留原始任务、当前状态和证据范围。超限先裁剪历史，再裁剪页面正文、阅读详情与目标表；固定约束装不下时明确失败。不存在候选选择模型、独立候选预算或另一份降级 context。

`history.excerpts` 保留历史正文、对应 documents/lang 和附件引用。不同语言声明的观察不合并；历史事实不代表当前状态，旧 target/ref 从正文剔除。语言以主文档声明和正文共同核对，不仅由 URL 前缀推断。

scroll 指定 target 时必须是当前可滚动容器；不指定则滚动页面。模型只给方向，执行器计算有界距离，节点使用真实 wheel 输入并检查命中。容器不可滚动时明确失败，不静默降级到整个页面。派发成功只证明操作发生，不等于内容已加载或验收通过。

停滞反馈、命令失败与未知副作用的处理见 [任务进度与恢复](general-workflow-optimization.md)。跨域父框裁剪、复杂几何、虚拟列表完整遍历及业务组件行为仍需独立验证；夹具通过不能替代真实业务验收。
