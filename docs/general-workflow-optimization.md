# 通用任务进度与恢复

当前执行只有单一 LLM 循环，具体字段和入口见 [Agent 简化架构](agent-loop-simplification-design.md)。原始要求和 acceptanceCriteria 不被计划生成或恢复逻辑改写。

## 进度与完成

`workflow.ts` 只维护原始要求账本。非结构化 objective 的显式编号可提取为稳定要求；无法可靠拆分时保留完整原文。结构化步骤直接使用原 description，不再生成局部计划、活动子目标、恢复预算或填写值缓存。

模型通过工具的 `progress.requirements`、`progress.criteria` 和 `progress.readings` 提交动作前已有事实。执行器核对身份与证据后先保存，再执行决定。requirements 的完成声明不是业务通过；criteria 仍按原 criterionId 和证据类型独立核验。缺少覆盖时不能 finish。

历史命令保存已发生及效果未知的操作，历史页面片段保留来源、正文和文档语言。旧 target 编号不能重放。阅读登记保留真实面板引文；已读内容只有明确重访原因时才允许再次打开。

## 有限恢复

动作后自动观察，当前状态与有界历史比较后给出 OBSERVATION_STALLED、REPEATED_STATE 或具体执行错误。新 target 编号、相同进度重复登记、重新调用模型不增加预算。收尾只允许保存已有结果或阻塞，不发起新浏览器操作。

DOM 前置检查明确未派发时，可以重新观察后在原预算内选择新动作；效果 UNKNOWN 立即停止，不能猜测写入没有发生。等待未命中不等于业务失败，允许有界观察恢复。缺失前提记录为阻塞，证据不足使用 INCONCLUSIVE，不伪造产品失败或通过。

setup 继续使用 PREPARING → CHECKING → READY。人工交还使旧观察和在途决定失效，保留已发生副作用事实，并重新核验身份及 policy。浏览器保持当前会话，不保存或重启身份基准。

模型滚动意图只接受 up/down/left/right。距离由执行器依据当前视口和容器计算，非法值给出具体格式说明；历史节点回执中的像素数不是模型参数。

## 验证边界

[Agent 测试](../tests/README.md)覆盖进度原子保存、证据引用、有限恢复、未知副作用停止、语言历史与滚动协议。HTTP 模型和页面夹具只验证协议及状态机，不代表真实供应商或业务验收。完整任务仍需使用真实模型与浏览器复核逐项结果。
